## 修复与代码清理

- 修正了启动页定时器在导航切换过程中覆盖引导页的问题，并增加回归测试。
- 首页轮播控制器按页面生命周期复用与释放，避免更新状态时重建控制器。
- 使用真实 Nunito 字体加载进行 Widget 渲染验证。
- 统一弹层白色背景和品牌素材，整理共用按钮、导航、标签、头像与颜色常量。
- 删除 65 个没有进入最终实现的生成 Dart 文件、4 个未使用的重复素材、临时 localhost 清单和默认计数器测试。
- 原稿 PNG 保留用于对照，运行 UI 均使用 Flutter Widget 实现。
- 截图驱动与夹具数据仅存在于 `test_driver/`，正常入口为 `lib/main.dart`。
